# wet_stone_2k - seamless procedural wet dark stone (2048x2048)
Generated by ../../scripts/make_wet_stone.py (numpy + PIL, deterministic seeds). All noise is FFT-periodic, tiles in U and V.

## Usage
- One tile = 2 m x 2 m for the causeway (slab joints every 1 m, 2x2 slabs per tile; ~1 mm/px detail at 2 m).
- Detail map: tile 4-8x finer than the base (i.e. 0.25-0.5 m per repeat) to keep grain sharp up close.
- Large glossy puddle patches are the most visible repeat; break them up in Unity with a world-space low-frequency tint/roughness variation, or by mixing 2 UV scales / decals.

## Files and channels
| file | content |
|---|---|
| wet_stone_albedo.png | sRGB colour, mean ~78, cool charcoal |
| wet_stone_height.png | 16-bit greyscale, linear, white = high |
| wet_stone_normal.png | tangent-space, OpenGL (+Y up, green up) - linear/non-sRGB import, Unity: Texture Type = Normal map |
| wet_stone_normal_dx.png | same with green flipped (DirectX, +Y down) |
| wet_stone_roughness.png | linear roughness 0.12-0.62 |
| wet_stone_ao.png | cavity AO |
| wet_stone_maskmap.png | HDRP Mask Map: R=metallic(0) G=AO B=detail mask(255) A=smoothness(1-roughness); sRGB OFF |
| wet_stone_orm.png | R=AO G=roughness B=metallic(0) (glTF style) |
| wet_stone_detail.png | HDRP Detail Map: R=albedo detail (grey, ~128) G=normal Y A=normal X B=smoothness detail (~128); sRGB OFF |
| wet_stone_preview_3x3.png / _roughness_3x3.png | 3x3 tiling previews, 2400 px |

Notes: all maps except albedo are linear data. Detail normal uses OpenGL Y.
